# MotionFolio

テキスト・画像・図形・glb アニメーションを自由に配置し、単体で開ける HTML に書き出すレイアウトエディター。

## 起動

`index.html` を Chrome か Edge で開く。インストールもサーバーも不要。

## 操作

| 操作 | 内容 |
| --- | --- |
| ツールバー / ドラッグ＆ドロップ | テキスト・図形・画像・glb を追加 |
| 「ページ」または左下の ＋ | テンプレート（表紙、章扉、図と本文、図と解説、ポーズ比較、手順、コード解説）からページを追加 |
| ダブルクリック | テキストは編集、3D は視点とポーズの調整、画像は差し替え |
| Shift + ドラッグ | 移動方向の固定、縦横比の固定（画像と 3D は逆に解除）、回転を 15° 刻み |
| Alt + ドラッグ | スナップを一時的に切る |
| 矢印キー | 1px 移動（Shift で 10px） |
| Ctrl+C / V / D | コピー、貼り付け、複製 |
| Ctrl+] / [ | 重ね順（Shift で最前面・最背面） |
| Ctrl+ホイール | 表示倍率 |
| Ctrl+S / O | プロジェクト（.mfolio）の保存と読み込み |
| Ctrl+B / I / U | 太字、斜体、下線（テキストを選んでいるだけなら全文に掛かる） |
| Ctrl+Shift+H | 強調色 |
| Ctrl+K | リンク |
| Ctrl+\ | 装飾を外す |
| Ctrl+Shift+K | キーキャップ（「Ctrl+Z」のように + でつないだ文字は 1 キーずつ囲む） |
| Ctrl+E | インラインコード |
| Ctrl+Shift+Y | マーカー |
| Ctrl+Shift+8 / 7 | 箇条書き（黒丸）／番号つき |
| Tab / Shift+Tab | 箇条書きの中で 1 段下げる／戻す |

箇条書きは右パネルで中黒・黒丸・ダッシュ・四角・チェック・矢印・番号・アルファベット・丸数字・かっこ数字・手順バッジから選ぶ。段落ごとに掛かり、テキストを選んでいるだけなら全文に掛かる。入れ子の段は段ごとに記号を選べる。カーソルを置いた段だけが変わる。記号を選んでいない段は、外側の段に合わせて深さで自動的に変わる（• → ◦ → ▪、1. → a. → i.、チェック・矢印・中黒は – → ◦）。

キーキャップ・コード・マーカーは、範囲を選んで掛けると囲み、もう一度掛けると外れる。何も選ばずに掛けると空の装飾ができ、続けて打った文字がその中に入る。もう一度押すと装飾の外へ出る。マウスの左・中・右ボタンの図は右パネルの「マウス」から文中に差し込む。

Mac では Ctrl の代わりに ⌘ を使う。

編集内容はブラウザ内に自動保存される。消した画像・glb のデータは取り消しで戻せるようにブラウザ内に残る。たまったときはツールバー右側の「未使用」ボタン（使っていないデータがあるときだけ出る）で削除できる。削除すると取り消しの履歴も消える。保存する .mfolio と書き出す HTML には、もともと使っているデータしか入らない。別の PC へ持ち出すときやバックアップには「保存」で `.mfolio` を作る。

## スマホで編集するとき

画面幅 760px 未満では、ツールバーはアイコンだけ、ページ一覧は下に横並びになる。右パネルは右下の「調整」で下から開く。

- ダブルタップ：テキストの編集、3D の視点調整、画像の差し替え
- 2 本指のピンチ：拡大縮小。何もないところをダブルタップするとフィットに戻る
- 指では範囲選択はできない。何もないところをなぞると拡大中の紙面がスクロールする

## 3D アニメーション

- 対応形式は glb（単体の gltf、vrm も可）。Draco 圧縮の glb はデコーダーをネットから取得するのでオンラインが必要。
- クリップ、速度、ループ、fps、グリッド、スケルトン、ワイヤー表示を右のパネルで切り替える。
- 再生バーは編集中もそのまま操作できる。黄色の印は記録されているキーフレームで、Shift を押しながらコマ送りボタンを押すと印へ飛ぶ。
- キーの印は次の順で決める。
  1. BlenderBook 教材用 GLB のアドオンで書き出した glb は、同梱された元のキー位置をそのまま使う。fps も「自動」なら glb の設定に合わせる。
  2. それ以外で全フレームが焼き込まれた glb は、値の変化から推定する。拾えるのは端点、動きが折り返す点、止まる点と動き出す点。動きの途中に滑らかにつないだキーは拾えない。
  3. 焼き込まれていない glb は、記録されたキーをそのまま使う。
- 再生とシークバーの範囲は、glb に書き出されたデータの最初から最後まで（Blender で 1 フレーム目から書き出せば 1 から始まる）。0 秒からは始めない。
- 右パネルの「終了フレーム」で、再生を途中のフレームで終えられる。空欄なら自動（データの最後まで）。データの最後より後を指定すると、最後のポーズのまま止めておく。最後以外で終えたときは、ループで最初へそのまま戻る。
- ループ再生では、最後のコマが最初のコマの 1 つ前に当たる周期アニメーション（歩行の 1〜24 フレームなど）を見分けて、もう 1 コマかけて最初へつなぐ。最初と最後が同じポーズのもの、つながらないものはそのまま最初へ戻る。
- 再生バーの ◀◆ ◆▶ ボタンは前後のキーフレームへ移動する。その向きにキーがなければ再生範囲の端へ行く。Shift を押しながらだと 1 フレームずつ動く。
- クリップが複数あるときは、右パネルで並び順と再生バーに出すかどうかを決められる。名前をクリックしたクリップが最初に表示される。
- 自動再生を切ると「開始（秒）」のポーズで止まった図になる。
- テンプレートの空の枠には glb や画像をドロップするか、ダブルクリックして選ぶ。

## 書き出し

「HTML 書き出し」は画像・glb・ビューアをすべて埋め込んだ 1 ファイルを作る。読者側でも再生、コマ送り、視点操作ができる。ブラウザの印刷から PDF にもできる。画像と 3D はクリックすると画面いっぱいに拡大して見られる（画像はクリック・Esc・×、3D はもう一度のクリック・外側のクリック・Esc・× で閉じる）。3D はドラッグすると拡大も閉じもせずに回る。

何も選択していないときの右パネルの「書き出す範囲」で、何ページから何ページまでを書き出すか決められる。「このページ」で表示中の 1 ページだけにもできる。範囲を絞ったときはファイル名の末尾に `_p3-5` のように範囲が付き、その範囲で使う画像と glb だけを埋め込む。プレビューも同じ範囲で作る。

何も選択していないときの右パネルで、読み方を選べる。

- ページ送り: 1 ページずつ表示し、矢印キーやボタンでめくる
- 縦スクロール: ページを縦に並べる
- 縦スクロール（つなげる）: ページの切れ目をなくし、1 枚の長い紙面にする

スマホ（画面幅 600px 未満）では、紙面を縮めずに要素を読む順に 1 段で並べ直す。文字は原寸（大きな見出しだけ少し小さく）、画像と 3D は幅いっぱい、図形は出さない。読む順は余白の広いところで上下・左右に切り分けて決めるので、段組みは左の段から読む。上部の「原寸で見る」で元の紙面に戻せる。書類の設定でオフにでき、「プレビュー」→「スマホで見る」で確かめられる。スマホの 3D は横になぞると回り、縦になぞるとページがスクロールする。

## 開発

`src/runtime.js`（ビューア）を変えたら `npm run build` で `js/runtime-src.js` を作り直す。`js/editor.js` と `css/editor.css` はビルド不要。
